# Stateworks Alpha 1 Example Pack

This directory is reserved for the vanilla-style example/resource pack used to demonstrate and test Stateworks Alpha 1.

The target systems are:

- Repeater
- Furnace
- Redstone Dust
- Crops
- Doors
- Trapdoors
- Buttons
- Saplings
- Lever
- Redstone Torch

The example pack should also serve as a practical reference for resource-pack authors.

See `docs/ANIMATION_FORMAT.md` for animation guidance.
